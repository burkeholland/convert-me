ConvertMe Features and FAQ

Everything you need to know about ConvertMe for Windows 11.

Features

  • Right-click images in File Explorer and convert from Show more options → Convert image.
  • Direct format choices convert immediately in a small progress window that closes when it succeeds.
  • Custom… opens the full window so you can pick format and quality for the whole batch.
  • PNG, JPG/JPEG, BMP, TIFF, WebP, and HEIC/HEIF. GIF is not included.
  • Writes new files next to the originals and never overwrites an existing name.
  • Optional Explorer menu. Turn it off in Settings. The app lives in the tray.

Frequently asked questions

Is ConvertMe free?

Yes. Download it from GitHub Releases.

Does it work on macOS?

No. ConvertMe is Windows 11 x64 only.

Which formats are supported?

PNG, JPG/JPEG, BMP, TIFF, WebP, and HEIC/HEIF. Animated WebP files use the first frame. GIF is intentionally left out of the first release.

Where do converted files go?

Next to the originals, using the same base name and the new extension. If photo.jpg already exists, you get photo (1).jpg.

Why does HEIC fail?

HEIC conversion needs the Windows HEIF Image Extensions codec. If it is missing, ConvertMe shows an install action that opens the Microsoft Store page for the codec.

Can I turn off the Explorer menu?

Yes. Settings → App → Explorer context menu. That choice is saved, so the menu is not re-added on the next launch.

Does it ask for administrator permission?

No. Registration is per-user.

What happens to transparency and metadata?

Transparent pixels flatten to white when the output format cannot store alpha. Compatible metadata is preserved when the target format allows it. Original file timestamps are kept.
