Convert Me test inputs

These small files are inputs for the conversion tests. Each one is synthetic: colour bars,
gradients and a sine tone made by a script. There are no real recordings or photos here.

They are generated by scripts\make-fixtures.py, which needs Python 3 with Pillow and a
full FFmpeg on PATH. That FFmpeg is a developer tool only. It is used to make inputs in
formats that Convert Me's own engine can read but cannot write (VP9, Opus, WMV and so
on). It is not part of the build and it is not shipped with the app.

The names say what is inside, for example vp9-opus.webm or picture-alpha.png.
truncated.mp4, not-really.png and garbage.mp3 are deliberately broken and must be
rejected with a clear message. av1-opus.mp4 and hevc-aac.mov use codecs the engine
cannot read, and must be refused by name.

photo.heic is photo.jpg saved as HEIC. It is made by scripts\make-heic-fixtures.ps1 with
the HEIC encoder of Windows, which needs Microsoft's HEIF Image Extensions and HEVC Video
Extensions on the PC. The engine cannot read it. The app reads it through Windows.

Regenerate with:  python scripts\make-fixtures.py
                  pwsh scripts\make-heic-fixtures.ps1
